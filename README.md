# 12306 列车运行图 · 任意区间查询

<img width="2463" height="1946" alt="image" src="https://github.com/user-attachments/assets/4e20e987-924a-4e5f-9a1a-146b706341c6" />

**输入任意两个车站（或城市），自动抓取该区间的全部车次，画成一张可视化的「运行图」。**

支持车型 / 席别 / 发车时间 / 票价筛选、余票高亮，以及「经某站中转」的两程联程查询。

---

## 快速上手

1. **双击 `启动.bat`** —— 自动探测本机 Python（3.10+），起好本地服务并打开浏览器；关闭窗口/Ctrl+C即停止服务。
2. 顶部填 **出发 / 到达**（城市或车站都行）→ 点「**换线路**」，等待抓取完成。
3. 换**乘车日期**：选好日期后点「**刷新数据**」—— 只改日期不会自动抓取（按钮会点亮提示），确认后才按新日期取数。
4. 查**中转**：点图上某个**站名** → 点「**刷新数据**」，两程车次叠加绘制。

>「刷新数据 / 换线路 / 中转查询」需要本地服务运行。

---

## 功能特性

- **任意区间查询**：始发 / 终到可填任何城市或车站，同城各站一并纳入；数据按区间分目录缓存，互不干扰。
- **运行图可视化**：每趟车一条横线，G / D / Z / T / K 与纯数字车次各有线型；滚轮缩放、拖动平移、双击重置。
- **通道自动划分**：一条干线常有多条走廊（郑州→常州 = 京沪 / 合杭 / 连镇），工具按每趟车**中间站集合的相似度**自动聚类分轴。兜大圈的绕行车会被拆成独立通道，不会横穿整张图；选项卡按趟数排序。通道名可在 `data/channel_aliases.json` 里自定义改成习惯叫法。
- **站点归并与档位**：站名 → 城市按 12306 官方车站表归并；纵轴按停靠比例分「全部站 / 主要站 / 枢纽站」三档。
- **同一趟车只出现一行**：起终站取跨度最大的一段；悬停起终站列可看全部可选组合。
- **筛选**：
  - **车型**（多选）、**席别**（默认二等座+硬卧+硬座）、**搜索车次**（支持纯数字与前缀）。
  - **发车时间 / 票价**双滑块：票价档位 = 本次查询里出现的**真实票价**（吸附拖动），轨道上等距铺开，低价区不拥挤、每档都拖得准；两端可收到同一档。
  - **票价口径跟着「仅看有票」走**：勾选时只算还有票的席位价格；未勾选时按全部票价（含售罄）筛选。
  - **始发站 / 终到站筛选**：只列实际出现的站，可多选；按「可选站集合」判断，所以「上海松江→武进」这种组合也筛得出。中转模式只筛线路两端。
- **余票展示**：可只看有票，或高亮有票车次；线条颜色 = 所选席别中等级最低且当前有票的那个。
- **中转联程查询**：点站名选中 → 刷新数据，实时抓取两程并叠加绘制；两程的**车型 / 席别分开选**；明细表按程分段、各自排序；中转多站用 6 种形状的点区分。
- **抓取并发**：页面底部「高级设置」可选 串行 / 3 / 6 并行（默认 6，被限流会自动停下并保留进度）。

## 命令行启动

```bash
python scripts/start.py                 # 默认 http://127.0.0.1:8765/
python scripts/start.py --port 9000     # 指定端口
python scripts/start.py --no-browser    # 只起服务不开浏览器
python scripts/start.py --date 2026-10-01
```

## 目录结构

```
ticket-request/
├── 启动.bat              一键启动脚本（双击即用）
├── 运行图原型.html        单文件前端（运行图 + 明细表）
├── data/                 缓存与数据集（JSON）
│   ├── viz_data.json       前端数据集（由 pipeline 生成）
│   ├── stations_city.json  站点表全字段（站名归并的依据）
│   ├── channel_aliases.json 通道别名表（可手改通道名）
│   ├── stops.json          经停站明细（按车次共享，换线路可复用）
│   └── routes/             各区间分目录缓存（<起>_<到>/）
└── scripts/
    ├── start.py          启动器：探测 Python → 起服务 → 开浏览器
    ├── server.py         本地 HTTP 服务 + 数据刷新 / 中转 API
    ├── pipeline.py       取数流水线（票价 → 经停 → 余票 → 通道聚类 → 注入 HTML）
    └── ...               MCP 客户端 / 审计 / 分析等辅助脚本
```

## 🔌 数据来源与刷新

数据源默认 **`auto`**：优先 `mcp-server-12306`（用于票价与余票），失败自动回退内置直连 12306 接口。可用环境变量 `TRAIN_SOURCE=mcp|urllib|auto` 强制指定。

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/data` | GET | 当前数据集 |
| `/api/refresh?date=&from=&to=&conc=6` | GET | 刷新数据；`from`/`to` 换区间，`conc` 指定并发 |
| `/api/status` | GET | 刷新进度与日志 |
| `/api/stations` | GET | 全部站名（起终点自动补全） |
| `/api/transfer?via=徐州&force=1` | GET | 经该站中转的两程车次 |
| `/api/legstops` | POST | 中转经停增量补全 |

## ⚠️ 说明

- 实时余票来自 12306 公开接口，高频调用会被限流；遇限流沿用上次快照并标注「余票未知」
- 站点档位阈值（30% / 70%）为经验值；车次极少的通道「主要站」会接近全部站点。
- 数据仅供个人学习研究，实时购票请以 12306 官方为准。
